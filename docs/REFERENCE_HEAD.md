# MakeHuman / MPFB reference asset provenance

The optional reference portrait uses an unmodified, textured MakeHuman / MPFB glTF character from the [vsim character library](https://github.com/kunalkushwaha/vsim/tree/main/packages/assets/library).

- Original model: https://github.com/kunalkushwaha/vsim/blob/main/packages/assets/library/human.glb
- Original provenance: https://github.com/kunalkushwaha/vsim/blob/main/packages/assets/library/CREDITS.md
- Original generating script: https://github.com/kunalkushwaha/vsim/blob/main/scripts/blender/make-human.py
- MakeHuman/MPFB bundled assets and generated exports: **CC0 1.0** according to the projects' published licenses.
- To acquire once: `python scripts/acquire_reference_head.py`. The source asset is then committed for offline use. No runtime network access.
- The original rig in this model does **not** implement an experiment's simulation or hair attachment.
- **Scale/fit and scalp landmarks still require visual inspection and calibration before treating this asset as a physically standardized scalp topology.**
- Projects can always supply their own heads and scenes.
